## 🚀 用户工作流

```bash
# 步骤1: 初始化项目
$ dnaskill init
> 选择类型: 客服支持
> 输入部门: 客服部
> 输入文档: ./faq.md
✅ 项目已创建

# 步骤2: 使用Claude生成（在Claude Code中）
$ cd generated-skills/customer-support
# 按照 GENERATION_GUIDE.md 的说明，使用 @dna-skill 生成

# 步骤3: 验证质量
$ dnaskill score ./SKILL.md
✅ 87/100 - Ready for deployment

# 步骤4: 部署使用
$ cp -r . ~/.claude/skills/
$ # 在Claude中使用 @customer-support
```

## 🔧 技术细节

### 架构
```
CLI (Commander + Inquirer)
  ↓
init → 创建项目结构 + 生成指导
  ↓
(用户使用 @dna-skill 生成)
  ↓
validate → 检查文件完整性
  ↓
score → Rubric评分（85分门槛）
```

### 核心模块
- `src/validators/rubric-scorer.mjs` (400行) - 评分引擎
- `src/cli/commands/init.mjs` (180行) - 初始化向导
- `src/cli/commands/score.mjs` (60行) - 评分命令
- `src/utils/` (120行) - 工具函数

### 测试覆盖
- 4个单元测试通过
- 1个完整示例验证
- Rubric评分器完整测试
