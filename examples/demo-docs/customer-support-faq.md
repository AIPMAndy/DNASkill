# 客服支持 FAQ

## 退款政策

### 退款条件
- 购买后30天内可申请退款
- 商品未使用且包装完好
- 提供购买凭证

### 退款流程
1. 客户提交退款申请
2. 客服审核资格
3. 财务处理退款
4. 3-5个工作日到账

### 特殊情况
- VIP客户可延长至60天
- 促销商品不支持退款
- 定制商品不支持退款

## 客服话术

### 标准回复
感谢您的咨询。我们会尽快为您处理。

### 升级规则
- 金额超过1000元需主管审批
- 涉及法律问题需转法务部
- 投诉需24小时内回复

## 禁止行为
- 不得承诺超出政策范围的退款
- 不得泄露客户隐私信息
- 不得擅自给予折扣优惠
